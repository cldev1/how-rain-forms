# Dew — How Rain Forms

A cheerful 3D toddler lesson (~3yo) that teaches how rain forms with **Dew** the dewdrop.

**Live:** https://how-rain-forms.vercel.app  
**Repo:** https://github.com/cldev1/how-rain-forms

## Stack

- Next.js App Router + React 19
- React Three Fiber + drei + three
- Web Speech (optional narrator) + Web Audio (soft click / friendly thunder)
- Client-only — no env vars, no API keys, no backend

## Local

```bash
npm i
npm run dev
```

Open http://localhost:3000
